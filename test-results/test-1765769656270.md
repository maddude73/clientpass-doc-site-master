2.  **Referral Record Creation**: A new record is created in the `referrals` database table with a **pending status**. This record contains all critical referral data, including client information, the specified service (`public.services`), and commission details. [SAD.md], [USE_CASE_MODELS.md], [SYSTEM_DESIGN.md]
3.  **Response Timer**: A 10-minute timer is set for the receiving professional to respond to the referral. [SAD.md], [REFERRAL_TIMERS.md]
4.  **Real-time Notification**: The system sends a real-time notification (e.g., push notification, SMS) to the identified receiving professional within 5 seconds, informing them of the new pending referral. ### 3. Receiver Action: Accept or Decline
