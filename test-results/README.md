# AI Provider Testing

This directory contains automated test results comparing AI provider responses.

## Files Generated

- `test-[timestamp].md` - Individual test results with full comparison
- Each file contains provider responses, timing data, and analysis

## Reading Test Results

Each test file includes:

- **Summary Table** - Quick comparison of all providers
- **Detailed Responses** - Full AI responses for each provider
- **Analysis Section** - Performance metrics and insights

## Example Analysis Points

- Response time comparison
- Response quality and formatting
- Source attribution consistency
- Error handling differences
